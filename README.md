# Krishika Infotech Solutions — Portfolio Website

A premium, dark-themed single-page portfolio for Krishika Infotech Solutions, a Kanpur-based web studio. Built to convert visitors into WhatsApp leads.

## Tech
React 18 · Vite · TypeScript · Tailwind CSS · Framer Motion · Three.js (R3F) · Embla Carousel

## Customize
All business info lives in **`src/lib/site.ts`**:
- `whatsapp` — your WhatsApp number in international format (e.g. `919876543210`, no `+`)
- `email`, `city`, `founders` — update freely
- Edit `src/components/Portfolio.tsx` to swap in real projects
- Edit `src/components/Testimonials.tsx` for real testimonials

## Run
```bash
bun install
bun run dev
```
